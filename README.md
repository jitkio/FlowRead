# FlowRead (浮读)

> **在流动中沉思：重新发现数字时代的深度阅读之美**

FlowRead 是一款专为重度阅读、论文研读与学术研究打造的现代化 Windows 桌面阅读与 AI 伴读软件。它摒弃了传统“复制粘贴到右侧聊天框”的割裂交互，将 AI 伴读能力无缝融合在原文与无纸化流式排版之间，让您在保持沉浸心流的同时，享受随选即问、来源可溯的智能阅读体验。

---

## 📦 下载与安装

FlowRead 即将在 GitHub Releases 中发布针对 Windows 平台的稳定打包版本（`.msi` / `.exe`）。届时您只需**直接下载安装包并双击安装**，即可开箱即用，无需配置复杂的开发环境或执行代码部署。

## 💡 核心功能与使用逻辑

FlowRead 的设计理念是**“以原文为锚，以伴读为伴”**。整个软件由以下五大核心功能模块有机联动构成：

```
┌─────────────────────────────────────────────────────────────────┐
│                      FlowRead 核心功能闭环                       │
└─────────────────────────────────────────────────────────────────┘
         │
         ├── 1. 多格式原生与流式双视图阅读 (PDF / TXT / MD / EPUB)
         │       └─ 原版版式视图 ⇄ 响应式流式重排 (KaTeX数学公式/Markdown排版)
         │
         ├── 2. PDF 深度结构化解析管线 (MinerU / Datalab Convert)
         │       └─ 异步后台解析任务 ➔ 结构块自动提取 ➔ 凭据本地安全托管
         │
         ├── 3. 选区划词与智能学习闭环 (Selection Toolbar)
         │       └─ 字符级高亮着色 ➔ 预设动作 (解释/翻译/简化) ➔ 底部精准Ask
         │
         ├── 4. 智能右侧伴读画布 (Right Companion Canvas)
         │       └─ 纵向自然对齐避碰 ➔ 五行精炼小卡 ➔ 一键平滑定位原文 ➔ 16:10大窗深潜
         │
         └── 5. 全书学习记录本与知识导出 (Notebook)
                 └─ 虚拟化无限浏览 ➔ 复合筛选 ➔ 一键导出 Markdown 知识库
```

### 一、多格式原生与双视图重排引擎

FlowRead 彻底打破了传统固定版式 PDF 的阅读局限，提供了“原版版式”与“流式重排”两种互通互补的阅读模式：

1. **原版版式视图 (Original View)**：
   - **高保真阅读**：支持 PDF、TXT、Markdown 及 EPUB 文档。内置优化的范围流加载技术，即使百兆级 PDF 也能秒级开启并流畅滚动；
   - **左侧结构微缩图 (Minimap)**：基于视口实际渲染提取结构热区，一键预览全文分布并快速拖拽导航。
2. **无纸化流式重排视图 (Fluid Reflow View)**：
   - **论文排版重塑**：针对学术论文密集的多栏、复杂数学公式排版，重排视图将其重塑为响应式单栏阅读体验，字号与行高随心调节；
   - **KaTeX 数学排版**：高精度解析并呈现复杂行内与跨行数学公式，避免 OCR 错漏与排版坍塌；
   - **独立位置记忆**：在原版视图与重排视图间切换时，软件会自动记忆并温和恢复各自的会话阅读位置，阅读节奏不被突兀打乱。

---

### 二、PDF 结构化云端解析管线

为了将静态的 PDF 扫描件或论文变为可交互的结构化知识，FlowRead 集成了先进的云端学术解析服务：

- **深度解析服务商支持**：内置对接 **MinerU** 与 **Datalab Convert** 解析引擎，将复杂 PDF 深度拆解为标题、段落、公式、代码块和高清图表切片；
- **非阻塞后台流水线**：解析过程在后台异步执行（支持准备、上传、解析中、下载与归一化等 9 阶段状态机），解析期间不阻碍任何本地阅读，任务完成后可选择自动或手动切换至流式重排；
- **原生凭据安全托管**：解析服务 API 密钥直接存储于 **Windows 凭据管理器 (Credential Manager)**，采用系统级原生加密，绝不落地为明文文件，断网安全隔离。

### 三、即时划词与学习闭环

在原版正文或重排正文中，划选文字即可触发核心学习流程：

1. **划选快捷工具条 (Selection Toolbar)**：
   - 鼠标划选任意句子或段落，悬浮工具栏即刻响应，提供常用伴读动作；
   - **支持高亮文字内再次拖选**：高亮层采用鼠标完全穿透机制，用户可以在已经着色的文字段落内部继续划取局部子句，发起针对性的细节提问，而不破坏已有标记。
2. **纯粹高亮着色（零 AI 配额消耗）**：
   - 支持多种温和高亮颜色，直接保存至本地数据库，仅用于视觉标记与沉思定位，绝不触发多余的 AI 请求。
3. **即时伴读动作**：
   - **解释 (Explain)**：深度拆解学术生词、晦涩术语或专业背景知识；
   - **翻译 (Translate)**：结合上下文的高水准双语互译，消除外文文献阅读障碍；
   - **简化 (Simplify)**：将冗长晦涩的长难句提炼为清晰凝练的逻辑骨架；
   - **提问 (Ask)**：针对选中的核心论点发起自由发问，支持在正文下方的沉浸提问栏直接输入。

---

### 四、右侧智能伴读画布与定位联动

AI 生成的伴读内容呈现在右侧专属画布上，与左侧正文形成高度默契的动态呼应：

1. **纵向自然对齐与智能避碰**：
   - 伴读卡片不局限于侧边堆叠，而是自动探测左侧对应原文在视口中的垂直坐标，卡片随原文纵向自然跟随；内置动态避碰算法，多张卡片密集出现时自动紧凑排开，互不遮挡。
2. **五行精炼小卡片**：
   - 默认采用“五行精简视图”呈现核心要点，一眼扫读，绝不让冗长的大段文字打乱主阅读心流。
3. **一键定位回到原文 (Jump to Source)**：
   - 点击卡片上的“回到原文”按钮，左侧阅读视口平滑滚动回当时选取的字句处，并伴随柔和的金色闪烁高亮；
   - **用户即时接管**：在平滑滚动定位途中，用户随时拨动鼠标滚轮或按下键盘翻页键，软件立即退出动画并完全把控制权交还给用户，彻底杜绝视口卡死或强制拉回。
4. **16:10 聚焦全屏大窗与多轮追问**：
   - 点击卡片展开图标，即可开启 16:10 黄金比例的聚焦详情窗口；
   - 在大窗内可对该处知识点展开**无限制的多轮深度对话**，追问历史自动归档，不污染主界面。

### 五、全书集中记录本与个人第二大脑同步

阅读不仅是摄入，更是沉淀。FlowRead 提供了系统化的知识整理中枢：

- **多维筛选记录本**：在右侧面板一键切换到「记录本」视图，支持按“全部 / 提问 Q&A / 高亮标记 / 指令卡片”快速筛选；
- **虚拟化游标翻页**：无论一本书积累了数十条还是上千条研读笔记，虚拟滚动列表均能保持如丝般顺滑的浏览手感；
- **一键导出 Markdown**：点击“导出全部”，即可将当前文档的全部原文摘录、AI 伴读解答及多轮追问完整输出为排版规整的 Markdown 文档，无缝导入 **Obsidian、Notion、Logseq** 等第二大脑知识库。

---

### 六、本地优先与隐私保护

- **本地离线数据库**：所有文档记录、划词锚点、伴读卡片、多轮追问历史均存储在您电脑本机的 SQLite 数据库（WAL 高性能模式）中，数据归您完全所有；
- **直连自定义大模型**：支持配置您自己的大模型 API 端点（如 DeepSeek、OpenAI 兼容接口等）。流式回答由客户端直连模型服务商，无任何第三方中转服务器截留您的阅读内容与思考数据。
