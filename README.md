# FlowRead (浮读)

> **在流动中沉思：重新发现数字时代的深度阅读之美**

FlowRead 是一款专为重度阅读、论文研读与学术研究打造的现代化 Windows 桌面阅读与 AI 伴读软件。它摒弃了传统“将内容复制粘贴到外部聊天框”的割裂交互，将 AI 深度伴读能力有机融合在原文与无纸化流式排版之间，让您在保持专注与心流的同时，享受随选即问、来源可溯的智能阅读体验。

---

## 🎯 FlowRead 是如何服务于用户的？

在长篇论文、专业著作与技术文档的研读过程中，读者往往面临四大核心痛点：**多栏排版拥挤难读**、**频繁切窗查询打断思考心流**、**笔记零散无法精准回溯原文**、以及**个人知识隐私面临云端泄漏**。

FlowRead 围绕**“以读者心流为中心，以原文位置为锚点”**构建服务逻辑：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        FlowRead 深度服务闭环                            │
└────────────────────────────────────────────────────────────────────────┘
          │
          ▼
【1. 视觉减负】 告别双栏拥挤 PDF ➔ 一键无纸化流式重排，字号行距呼吸自如，KaTeX 公式毫秒级高保真呈现
          │
          ▼
【2. 心流驻留】 遇难懂词句无需跳出 ➔ 原文直接划词，五行精炼卡片在右侧横向对齐出现，阅读绝不卡壳
          │
          ▼
【3. 深度探究】 浅尝辄止不过瘾 ➔ 支持高亮文字内再次拖选追问，一键展开 16:10 聚焦大窗进行无限多轮对话
          │
          ▼
【4. 溯源无忧】 随时想查上下文 ➔ 卡片一键平滑滚动回原文对应句子并伴随金色闪烁，鼠标拨动即时退出接管
          │
          ▼
【5. 资产沉淀】 从零碎输入到知识内化 ➔ 全书记录本集中归档，一键完整导出 Markdown 融入您的第二大脑
          │
          ▼
【6. 隐私无忧】 本地数据优先 ➔ 数据库全留存本机，大模型直接从客户端直连，绝不经由第三方服务器截留
```

### 1. 从“拥挤难读”到“清爽沉浸”
学术论文通常采用紧凑的双栏排版与小字号印刷，在屏幕上阅读时需频繁手动放大平移。FlowRead 的**流式重排引擎**将密集的 PDF 重构为舒适的现代单栏排版，配合高保真 KaTeX 数学公式渲染与原版/重排双视图独立位置记忆，让阅读回归愉悦与专注。

### 2. 从“频繁切窗”到“心流驻留”
以往遇到生词公式或长难句，需要复制、切出窗口、粘贴进大模型网页、等待回答再切回，思维链条被严重粉碎。在 FlowRead 中，划选文字即可触发快捷工具栏，点击“解释”、“翻译”、“简化”或“Ask”，右侧伴读卡片**在垂直维度自动对齐左侧原文位置**呈现，核心信息浓缩在**五行小卡片**中，一瞥即可获得解答，阅读节奏丝毫不被打断。

### 3. 从“浮光掠影”到“深度探究”
FlowRead 拥有独特的**高亮层鼠标穿透与字符级二次拖选技术**。您不仅可以对一段正文打上高亮标记，更可以在已着色的文本内部直接划选其中某几个词发起针对性追问；针对需要推演的复杂理论，点击卡片即可展开 **16:10 沉浸式大窗**，在专注界面中与 AI 展开无限制的多轮深度对话。

### 4. 从“阅读遗忘”到“精准溯源”
做过笔记的地方往往在几天后忘记对应哪段文字。FlowRead 的伴读卡片始终带有确定的文本哈希与结构定位锚点，点击卡片上的“回到原文”按钮，左侧视口将平滑滑动并精准闪烁高亮对应句子；更重要的是，在平滑滑动途中，**只要您轻轻拨动滚轮或按下翻页键，软件立即将视口控制权完整还给您**，彻底杜绝机械化强制锁定。

### 5. 从“零散碎片”到“第二大脑”
所有的提问回答、高亮摘录与翻译记录，都会自动汇流到「全书学习记录本」中。在阅读完成后，点击“导出全部”，软件会将整部书籍的学习笔记完整排版为规范的 **Markdown 文档**，一键拖入 **Obsidian、Notion、Logseq** 等个人知识库，完成从“读到”到“拥有”的闭环。

### 6. 从“数据担忧”到“绝对隐私”
对于严谨的研究者，文献思考与阅读记录是宝贵的智力资产。FlowRead 的数据架构坚持**本地优先（Local-First）**：所有阅读历史、笔记数据均存储在您电脑本机的 SQLite 数据库中；云端解析 Token 托管于 Windows 系统级凭据管理器；大模型调用直接从客户端发起，绝不存在任何第三方中间服务器收集您的阅读足迹。

## 💡 核心功能全览

FlowRead 的完整功能架构由以下互为支撑的业务子系统组成：

```
┌─────────────────────────────────────────────────────────────────┐
│                      FlowRead 核心功能矩阵                       │
└─────────────────────────────────────────────────────────────────┘
         │
         ├── 1. 多格式原生与流式双视图阅读 (PDF / TXT / MD / EPUB)
         │       └─ 原版版式视图 ⇄ 响应式流式重排 (KaTeX数学公式/Markdown排版)
         │
         ├── 2. PDF 深度结构化解析管线 (MinerU / Datalab Convert)
         │       └─ 异步后台解析任务 ➔ 结构块自动提取 ➔ 凭据本地安全托管
         │
         ├── 3. 选区划词与智能学习闭环 (Selection Toolbar)
         │       └─ 字符级高亮着色 ➔ 预设动作 (解释/翻译/简化) ➔ 底部精准Ask
         │
         ├── 4. 智能右侧伴读画布 (Right Companion Canvas)
         │       └─ 纵向自然对齐避碰 ➔ 五行精炼小卡 ➔ 一键平滑定位原文 ➔ 16:10大窗深潜
         │
         └── 5. 全书学习记录本与知识导出 (Notebook)
                 └─ 虚拟化无限浏览 ➔ 复合筛选 ➔ 一键导出 Markdown 知识库
```

### 一、多格式原生与双视图重排引擎
- **高保真原生阅读**：原生支持 PDF、TXT、Markdown 及 EPUB 文档，采用范围流分页加载，百兆大文件秒开；
- **左侧结构微缩图 (Minimap)**：根据渲染视口实时呈现全文缩略图，一键拖动导航；
- **无纸化流式重排 (Fluid Reflow)**：密集双栏学术排版秒变响应式现代排版，字号、行距自适应调节；
- **KaTeX 数学保真排版**：高精度支持复杂行内公式与独立块级公式，排版无坍塌；
- **独立阅读位置保持**：在原版视图与流式重排视图之间来回切换时，独立记忆并温和恢复各自的滚动位置。

### 二、PDF 结构化云端解析管线
- **高精度学术解析集成**：支持对接 **MinerU** 与 **Datalab Convert** 解析引擎，将复杂论文拆解为标题、段落、公式、代码块和高清图表切片；
- **非阻塞后台流水线**：9 阶段状态机，断点续传、失败恢复，解析全程不干扰本地阅读；
- **Windows 原生凭据托管**：密钥存放在 **Windows Credential Manager** 中，加密隔离，不落盘为明文，断网安全防泄露。

### 三、即时划选与学习闭环
- **悬浮划词工具条 (Selection Toolbar)**：鼠标划选文字即刻呼出，提供解释、翻译、简化与自由 Ask；
- **纯粹高亮着色（零 AI 配额消耗）**：多种高亮色彩自由标记，仅存本地，绝不浪费 AI Token；
- **高亮层鼠标穿透与二次拖选**：已高亮区域不阻断鼠标，可在高亮字句内部再次拖选局部子串发起深层提问。

### 四、智能伴读画布与定位联动
- **纵向自然对齐与动态避碰**：卡片根据对应原文在视口中的垂直坐标自适应跟随，多张卡片自动紧凑排开；
- **五行精炼小卡片**：提炼关键回答，不遮挡、不冗余、不打断主阅读心流；
- **一键定位回到原文 (Jump to Source)**：点击卡片一键平滑滚动回对应原文并附金色闪烁；滚动期间轻拨滚轮或按方向键即时接管，自由浏览绝不卡死；
- **16:10 聚焦大窗与无限追问**：黄金比例大窗展示完整解答，针对单点知识展开无限多轮追问。

### 五、全书集中记录本与个人第二大脑同步
- **集中化多维分类**：随时切换至「记录本」视图，按全部、提问、高亮、指令卡片分类检索；
- **虚拟化游标翻页**：海量卡片流畅翻阅，支持卡片快速回溯原文；
- **一键导出 Markdown**：点击“导出全部”，完整格式化导出为 Markdown 文档，直接无缝导入 Obsidian / Notion / Logseq。
